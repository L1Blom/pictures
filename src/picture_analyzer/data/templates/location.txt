=== LOCATION DETECTION SECTION ===
12. **Location Detection**: Determine the geographic location.
    - **LANDMARK IDENTIFICATION** (highest priority): If you recognize a specific landmark, monument, famous building, or named place, identify it explicitly in the `landmark_name` field. Examples: "Eiffel Tower", "Ponte Sant'Angelo", "Florence Baptistery", "Canterbury Cathedral". Also read any visible signs, plaques, or text that name a location.
    - **DESCRIPTION CONTEXT**: If the description context below contains a location, it represents the general area (e.g. "Paris, France" or "Toscane, Italy"). Use it as a starting point, but try to find a MORE SPECIFIC location within that area based on what you see. Only fall back to the context location if you cannot identify anything more specific.
    - If no landmark is recognized and no context is provided, infer from visual clues:
      - Visible signs, text, license plates, street markers
      - Architecture style and construction materials
      - Vegetation and landscape type
      - Road/infrastructure style
      - Vehicle types and styles
    - `landmark_name`: name of the recognized landmark, or empty if none
    - `country`, `region`, `city_or_area`: the most specific location you can determine
    - confidence: 0-100
      - 95-100: specific landmark identified by name
      - 80-94: landmark or location identified from visual clues with high certainty
      - 50-79: general region inferred from architecture/landscape
      - 0-49: no geographic clues, using context fallback or unknown
    - reasoning: briefly explain whether the location came from a landmark, visual clues, or the description context
    - Write all values in full — do NOT abbreviate or truncate with "…" or "..."
