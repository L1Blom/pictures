=== ENHANCEMENT RECOMMENDATIONS SECTION (DETAILED & QUANTIFIABLE) - ALWAYS IN ENGLISH ===
12. **Lighting Quality Assessment**: 
    - Current state: underexposed/properly exposed/overexposed
    - Specific measurements: estimated EV adjustment needed (-1.5 to +1.5)
    - Shadow detail: crushed/normal/blown out
    - **CRITICAL**: If underexposed, MUST recommend specific brightness increase percentage in recommendations (see section 17)
    - **CRITICAL**: If overexposed, MUST recommend specific brightness decrease or highlight reduction in recommendations
    - Specific recommendation: e.g., "increase brightness by 25-30%", "reduce highlights by 15%"

13. **Color & White Balance Analysis**:
    - Dominant colors and their intensity
    - Color temperature assessment: warm (K), neutral (K), cool (K) - estimate Kelvin temperature
    - Detected color casts: none/slight warm/strong warm/slight cool/strong cool
    - Saturation level: desaturated (recommend +15-30%)/normal/oversaturated (recommend -10-20%)
    - **CAST DIRECTION SELF-CHECK (do this before recommending any color correction)**:
      * WARM cast = image looks orange/yellow/golden (typical aged slides). Fix = cool shift / reduce red / increase blue.
      * COOL cast = image looks blue/cyan/gray-blue. Fix = warm shift / increase red / reduce blue.
      * Before writing your recommendation, verify: does the recommended correction OPPOSE the cast you described? If you described a cool cast and are about to increase blue — STOP, that is wrong. If you described a warm cast and are about to warm it further — STOP, that is wrong.
      * Neutral whites (paper, snow, shirts) are the reference: if whites look yellow/orange → warm cast; if whites look blue/gray → cool cast.
    - **Only recommend color channel adjustments if you actually see a color cast in the image.**
    - **HARD RULE — NEUTRAL IMAGES GET NO COLOR CORRECTION**: Before recommending any color correction, check the neutral references (whites: paper, snow, shirts, walls; greys: pavement, shadows). If whites/greys look neutral (no visible yellow/orange/blue tint), the image has NO cast — you MUST NOT recommend COLOR_TEMPERATURE, RED_CHANNEL, BLUE_CHANNEL, or GREEN_CHANNEL. "Slightly warm" or "mildly cool" is NOT a cast. When in doubt, recommend nothing — an unnecessary color correction CREATES a cast that was not there (this is the single most common over-correction error).
    - If a STRONG warm/orange/yellow cast is clearly visible:
      * COLOR_TEMPERATURE: cool by 300-600K (proportional to cast severity)
      * RED_CHANNEL: reduce by 5-12% (only if reds/oranges are visibly dominant)
      * BLUE_CHANNEL: increase by 5-10% (only if blues are visibly deficient)
      * GREEN_CHANNEL: increase by 3-8% (only if greens are visibly muted)
      * VIBRANCE: increase by 10-20%
      * **IMPORTANT**: COLOR_TEMPERATURE cool shift and BLUE_CHANNEL increase both push the image cooler. Do NOT use both at full strength — if you apply a COLOR_TEMPERATURE cool shift of 400K+, either omit BLUE_CHANNEL entirely or cap it at 3-5%.
    - If only a SLIGHT warm cast or the image looks well-balanced: recommend only BRIGHTNESS and VIBRANCE. Skip channel corrections entirely.
    - If the image already looks color-neutral or cool: do NOT recommend any channel or temperature corrections.
    - **CRITICAL — COOL CAST IMAGES**: If the color analysis detects a COOL cast (bluish, blue-gray bias, or estimated Kelvin above ~4700K with cool description), you MUST NOT recommend BLUE_CHANNEL increase or COLOR_TEMPERATURE cool shift. Increasing blue on an already-cool image makes it worse. Instead:
      * If the cool cast is slight: skip all channel/temperature corrections
      * If the cool cast is strong: recommend COLOR_TEMPERATURE: warm by 200-400K and/or BLUE_CHANNEL: reduce by 3-8%
    - **NATURAL WARM LIGHT IS NOT A CAST**: evening/golden-hour/indoor-tungsten warmth is part of the photo's atmosphere. If the warm tone is consistent with the scene's lighting (e.g. late-afternoon outdoor scene, cozy indoor gathering), do NOT correct it — note it as natural and skip color corrections.

14. **Sharpness, Clarity & Noise**:
    - Overall sharpness: soft/slightly soft/sharp/oversharpened
    - Specific areas with blur (if any): specify location and severity
    - Noise assessment: none/minimal/moderate/high - recommend noise reduction if needed
    - Clarity recommendation: e.g., "apply unsharp mask (radius=1.5, amount=80%)", "boost local contrast by 20%"
    - Specific recommendation: e.g., "increase sharpness by 30%", "apply moderate noise reduction"

15. **Contrast Enhancement**:
    - Current contrast level: very low/low/normal/high/very high
    - Recommended adjustment: specific percentage e.g., "increase contrast by 25%"
    - Shadow/midtone/highlight adjustments if needed: e.g., "brighten shadows by 15%, boost highlights by 10%"
    - Local contrast enhancement: recommend unsharp mask or clarity boost with specific values

16. **Composition & Technical Issues**:
    - Any visible defects: dust spots, scratches, artifacts, distortion
    - Vignetting: none/slight/moderate/strong - recommend correction %
    - Chromatic aberration: none/slight/present - recommend correction approach
    - Straightness: perfectly level/slightly tilted/noticeably tilted
    - Specific fixes needed: e.g., "remove 2-3 dust spots", "correct 2-degree tilt"

17. **Recommended Enhancements** (prioritized list with specific parameters - REQUIRED FORMAT):
    - IMPORTANT: Always use this EXACT format for EVERY enhancement recommendation
    - Each line must start with: "ACTION: description with percentage or parameter"
    - **MANDATORY: recommended_enhancements must NEVER be an empty list. Even for well-exposed images, scanned slides always benefit from at least SHARPNESS + VIBRANCE.**
    - **BRIGHTNESS ADJUSTMENT FOR EXPOSURE**
      * GOAL: a pleasing family-album photo — bright, lively, engaging. When in doubt, lean brighter rather than dimmer.
      * Judge darkness by actual shadow detail: if shadows are crushed or faces are hard to see, the image is genuinely underexposed and needs a REAL brightness lift.
      * If image is clearly underexposed (very dark, crushed shadows): include "BRIGHTNESS: increase by X%" (15-40%; scale with severity — a slide where faces are barely visible needs 30-40%, not 5%)
      * If image is moderately dark (dull but detail visible): "BRIGHTNESS: increase by 10-20%"
      * If image looks slightly dim but mostly correct: 5-10%
      * If image is well-exposed: skip BRIGHTNESS
      * If image is overexposed: include "BRIGHTNESS: decrease by X%"
      * WARNING: Do NOT combine BRIGHTNESS + SHADOWS + CONTRAST all at once — this will massively overbrighten. Choose ONE exposure correction only.
    - **MONOCHROME IMAGES**: If the image is black & white / grayscale / sepia-toned monochrome, NEVER recommend COLOR_TEMPERATURE, RED_CHANNEL, BLUE_CHANNEL, GREEN_CHANNEL, SATURATION, or VIBRANCE corrections — there is no color to correct. Focus on BRIGHTNESS, CONTRAST, SHARPNESS, and SHADOWS/HIGHLIGHTS instead. (A folder-level "Enhancement: black" hint may exist, but you must detect monochrome per-image regardless.)
    - **COLOR CORRECTIONS — only include if the cast is clearly visible in the image**:
      * **HARD RULE: if whites/greys look neutral, include ZERO color corrections** (no COLOR_TEMPERATURE, no channel adjustments) — see section 13. An unnecessary correction creates a cast that was not there.
      * Do NOT add RED_CHANNEL, BLUE_CHANNEL, GREEN_CHANNEL, or COLOR_TEMPERATURE corrections unless you can actually see an imbalance in the neutral references
      * If you see a clear warm/orange cast: see section 13 for appropriate ranges
      * If the image looks color-neutral or well-balanced: skip all channel corrections entirely
      * If the image has a COOL cast (bluish): NEVER increase BLUE_CHANNEL — this compounds the problem. See section 13 for cool-cast handling.
      * **COMPOUNDING WARNING**: COLOR_TEMPERATURE cool shift + BLUE_CHANNEL increase are NOT additive — they compound. If you recommend COLOR_TEMPERATURE cool by 400K or more, do NOT also recommend BLUE_CHANNEL increase (or cap at 3%).
    - **CRITICAL**: NOISE_REDUCTION MUST have a numeric strength value (e.g., "apply 20%", "apply 35%") - NEVER use words like "light", "moderate", "heavy" without a percentage
    - Examples of CORRECT format: 
      * "BRIGHTNESS: increase by 7%"
      * "CONTRAST: boost by 20%"
      * "SATURATION: increase by 15%"
      * "COLOR_TEMPERATURE: warm by 500K" (or "COLOR_TEMPERATURE: cool by 800K" for removing orange)
      * "SHARPNESS: increase by 30%"
      * "NOISE_REDUCTION: apply 25%" (MUST be numeric percentage)
      * "RED_CHANNEL: reduce by 8%" (only if a warm/orange cast is clearly visible)
      * "BLUE_CHANNEL: increase by 8%" (only if blues are visibly deficient)
      * "GREEN_CHANNEL: increase by 5%" (only if greens are visibly muted)
      * "GREEN_SATURATION: increase by 20%" (to restore green vibrancy)
      * "UNSHARP_MASK: radius=1.5px, strength=80%, threshold=0"
      * "SHADOWS: brighten by 8%"
      * "HIGHLIGHTS: reduce by 10%"
      * "VIBRANCE: increase by 20%"
      * "CLARITY: boost by 20%"
      * "YELLOW_CAST_REMOVAL: shift to neutral" (alternative for extreme cases)
    - DO NOT use phrases like "maintain", "normalize", "none needed", "as is"
    - DO NOT forget the percentage, value, or parameter for each action - EVERY recommendation must have a numeric value
    - List in order of priority/impact (COLOR_TEMPERATURE + RED_CHANNEL + BLUE_CHANNEL + GREEN_CHANNEL should ALWAYS be top 4 for warm/orange casts)
    - ALWAYS include at least 3-5 specific enhancement recommendations
    - **MINIMUM BASELINE for any scanned slide (even well-exposed ones): "SHARPNESS: increase by 20%" + "VIBRANCE: increase by 15%" — these two are always appropriate.**
    - **REMINDER: For images that look like they're from 1950-2000 AND have a visible WARM/orange cast, recommend COLOR_TEMPERATURE cool shift + RED_CHANNEL reduce. BLUE_CHANNEL increase is OPTIONAL and should only be included if the warm cast is strong AND blues are visibly deficient. If the image already has a neutral or cool color balance, skip channel corrections entirely.**

18. **Overall Enhancement Priority**:
    - Which issue is most critical to fix first
    - Estimated improvement percentage if all recommendations applied
    - Preservation notes: aspects that should NOT be changed to maintain character

19. **Field Verbosity Requirement (applies to the JSON output below)**:
    - The final JSON has one string value per field (lighting_quality, color_analysis, sharpness_clarity,
      contrast_level, composition_issues). Each of these strings MUST pack in the specific sub-details from
      the matching numbered item above (12-16) — never collapse a field down to a single short label.
    - "lighting_quality" MUST include: current state + EV estimate + shadow detail, e.g.
      "properly exposed; EV: +0; shadows: normal, no crushed detail" — NOT just "properly exposed".
    - "color_analysis" MUST include: dominant colors + estimated Kelvin temperature + cast severity + saturation
      assessment, e.g. "warm cast (~4200K), moderate; saturation normal, slight boost recommended" — NOT just
      "warm cast detected, saturation normal".
    - "sharpness_clarity" MUST include: overall sharpness + any localized blur + noise level, e.g.
      "slightly soft overall, no localized blur, noise minimal" — NOT just "slightly soft".
    - "contrast_level" MUST include: current level + the specific shadow/midtone/highlight adjustment, e.g.
      "normal; boost shadows 10%, highlights unchanged" — NOT just "normal".
    - "composition_issues" MUST include: defects/vignetting/chromatic aberration/tilt, or explicitly state
      "none visible" for each aspect if truly clean — NOT just "none visible" alone with no aspects listed.
